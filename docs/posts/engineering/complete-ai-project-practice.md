# 完整项目实战

这一篇不是再补某个局部知识点，而是把前面几步全部串起来，看一个完整的 AI 原型项目到底怎么落。

## 一个可交付的最小项目流程

1. 先选一个单场景点子
2. 明确用户、输入和输出
3. 画出最小页面原型
4. 接入 Prompt 与模型请求
5. 做状态、重试和结果展示
6. 部署一个可访问版本
7. 写一份复盘

## 为什么“复盘”也算实战的一部分

因为没有复盘，项目就只是一次性完成；有复盘，项目才会变成你自己的知识资产。

## 这一步做完后意味着什么

说明你已经不只是“会调接口”，而是开始具备：

- 做产品原型
- 组织交互
- 判断价值
- 积累经验

这也是从新手进入真正产品化阶段的分水岭。
