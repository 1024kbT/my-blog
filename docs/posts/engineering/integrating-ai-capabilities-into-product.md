# 接入 AI 能力

这一篇关心的不是页面，而是把 AI 真正接进产品时，最核心的几层到底是什么。

## 最小接入链路

我会只看四层：

1. 用户输入
2. Prompt 组织
3. 模型请求
4. 结果展示

## 新手最容易忽略的是 Prompt 组织

很多人接入模型时，直接把用户输入原样发出去。更稳的做法是至少拆成：

- 系统角色
- 用户任务
- 输出格式
- 额外约束

这样页面体验才不会飘来飘去。

## 接能力时最值得先做好的东西

- 失败重试
- 超时提示
- 返回结果的基础格式化
- 限制过长输入

这些看起来不酷，但都是产品体验的底子。

## 什么时候算“接上了”，不是“勉强跑了”

如果你的页面已经能做到：

- 用户知道怎么开始
- 返回结果结构基本稳定
- 失败时有下一步

那才算是真正接上。
