# 零基础入门：从会用到会搭一个 AI 小工具

零基础阶段最容易掉进两个坑：一个是只看概念不动手，另一个是刚开始就想上复杂架构。更稳的做法是先做出一个小工具，再用它反过来理解模型、提示词和交互。

## 这个阶段到底要学会什么

我会把目标压缩成四件事：

1. 知道模型调用是什么。
2. 知道提示词为什么会影响结果。
3. 能搭出一个最小可运行页面。
4. 能把一次请求、一次响应和一次错误处理讲清楚。

## 推荐的学习顺序

### 第一步：先理解最小调用链路

不要先学“所有 AI 概念”，先理解一个最小链路：

- 用户输入
- 前端提交请求
- 模型返回结果
- 页面展示输出

只要这条链路通了，后面学上下文、多轮、工作流才有落点。

### 第二步：先学会写可复用提示词

零基础时的提示词不用搞得像论文，先做到这三点就够：

- 角色明确
- 输出格式明确
- 输入范围明确

比如让模型输出摘要、表格、待办清单，都比“随便问一句”更能让你理解提示词的边界。

### 第三步：做一个最小作品

我建议从下面三类里挑一个：

- 摘要助手
- 改写助手
- 问答助手

目标不是炫技，而是让你第一次把输入、请求、结果、错误状态完整串起来。

## 这个阶段的知识清单

- 模型 API 的基本请求方式
- 前后端最小数据流
- 基本提示词结构
- 加载中 / 失败 / 成功三种状态
- 简单的部署方法

## 一个合格的阶段输出长什么样

到了零基础阶段末尾，我会要求自己至少能交出：

- 一个能运行的小工具
- 一篇“这个工具是怎么做的”短总结
- 三到五个自己试过的提示词模板

只要这三样都有，你就不是“只会聊天”，而是已经开始进入 AI 应用开发了。

## 常见误区

### 误区一：一开始就研究 Agent

这会让人很快失去手感。你连最小调用链都没跑过，谈 Agent 只会停在名词层。

### 误区二：把前端框架学习和 AI 学习混成一坨

要拆开看。AI 能力是 AI 能力，前端工程是前端工程。你只需要先有一个足够简单的载体，把它们接起来。

### 误区三：只追求“回答好不好”

早期更重要的是把请求链路和状态处理建立起来，而不是单纯比较模型回答谁更聪明。

## 下一步怎么进入初中级

当你已经能做出一个最小工具，并且知道提示词、接口和页面是怎么接起来的，就可以进入下一层：

- 多轮对话
- 结构化输出
- Prompt 模板复用
- 部署可访问 Demo
