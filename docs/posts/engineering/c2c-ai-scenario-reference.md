# AI 消费场景灵感参考（C 端）

C 端场景更强调：

- 易上手
- 即时反馈
- 情绪价值
- 高频回访

## 比较典型的方向

### 1. 表达辅助

写作、改写、润色、标题生成、社媒内容辅助。

### 2. 个人效率

总结、待办、计划、复盘、资料整理。

### 3. 个人陪伴与互动

问答、角色互动、陪练、学习反馈。

### 4. 内容消费升级

把长内容拆成更容易吸收的形式，比如摘要、标签、重点提取。

## C 端最重要的判断标准

不是“是不是很强”，而是“愿不愿意每天回来用一下”。
