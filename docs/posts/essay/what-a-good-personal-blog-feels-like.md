# 一个好的个人博客，应该给人什么感觉

我越来越觉得，一个好的个人博客未必是最炫的，但它应该是“让人愿意停下来”的。

## 第一眼不是全部

很多个人站第一眼都很强：动画、光效、整齐卡片、大标题。  
但如果继续往下看，发现没有内容、没有脉络、没有更新痕迹，那种惊艳会很快散掉。

所以我现在更在意的是：

- 读者能不能立刻知道这里主要写什么
- 有没有持续更新的迹象
- 旧文章是不是也方便找到
- 页面是不是让人想继续点下一篇

## 气质比花活更长久

我喜欢有点个性的站，但不再追求每一处都在“证明我很会前端”。

真正能留下来的博客，通常会给人一种比较稳定的感觉：

- 内容放在第一位
- 风格有辨识度，但不喧宾夺主
- 读起来轻松，找内容也轻松

## 博客也是一种自我理解

写博客不只是输出信息。你在怎么分类、怎么命名、怎么摆放文章，其实也在暴露你怎么看待自己的兴趣和经验。

所以一个好的博客，不只是“内容很多”，而是它能慢慢长成一个比较诚实的自己。
